# Pengawasan

Aplikasi ini bisa dipasang di ponsel sebagai PWA melalui browser.

## Pasang di ponsel

1. Buka https://mediakopena-arch.github.io/Pengawasan/ di Chrome (Android) atau Safari (iPhone).
2. Android: tekan tombol **Pasang** pada ajakan di aplikasi atau buka menu browser lalu pilih **Instal aplikasi**. iPhone: pilih **Bagikan** lalu **Tambahkan ke Layar Utama**.
3. Buka ikon Pengawasan dari layar utama. Di Android pilih menu Chrome **Instal aplikasi** atau **Tambahkan ke layar utama**. Di iPhone, pilih **Bagikan** → **Tambahkan ke Layar Utama**.

Halaman utama dapat dibuka kembali saat offline setelah kunjungan pertama.
